# 文枢图标资源

- `icon.png` 是当前 Windows 图标的可编辑栅格源文件。
- `icon.ico` 包含 16、20、24、32、40、48、64、128 和 256 像素的 32 位 RGBA 图层，供后续
  electron-builder 直接使用其默认的 `build/icon.ico` 约定。

## 权利来源

本图标由项目所有者于 2026-08-28 明确授权在 TASK-012 WP2 中自行生成；使用 OpenAI 内置
ImageGen（`gpt-image-2`）根据“深蓝底、折页文档、朱砂笔划”的原创提示词生成。它不是从网络下载的
素材，也不是现有功能性 SVG 的改名或复用。生成文件保留其 C2PA 来源元数据；本仓库保留 PNG 源和由其
导出的 ICO，方便后续审计与替换。
