The archive groups 40 task documents, each with a Chinese and English version, under Tasks 001–012. Plans describe the scope, fixed decisions, and acceptance criteria at the time. Execution prompts preserve work-package instructions; WP (work-package) reports record intermediate evidence; completion reports record final results. For current capabilities, prioritize completion reports and the [project home](../../README.en.md).

These documents preserve dates, versions, test counts, and release decisions from each stage. Historical plans must not be interpreted as a current backlog or new authorization to act. Task files formerly in the `docs/` root now live in numbered subdirectories, retaining their filenames. Repository paths in the text point to current locations except for explicitly labeled historical command output. Commands still run from the repository root.
