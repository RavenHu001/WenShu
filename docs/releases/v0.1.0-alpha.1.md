## 使用方式

- portable：下载后校验 SHA-256，放到普通用户可写目录后启动；它不会安装系统级组件。
- NSIS：校验后运行安装器，按提示执行当前用户安装；默认不提权。卸载只删除应用安装内容，不应
  删除用户选择的外部工作区。
- 两种产物都没有自动更新。获取修复版需手动下载并重新校验。
- MIT 源码可通过 GitHub 公开；portable/NSIS 当前只保留在内部 Draft，不作为公开下载，也不计划提交
  Microsoft Store。Artifact Signing + GitHub OIDC 仅作为未来公开二进制时的可选工作。

## SHA-256 校验

将两个 EXE 与 `SHA256SUMS.txt` 放在同一目录，在 PowerShell 中逐项运行：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\WenShu-0.1.0-alpha.1-portable-x64.exe'
Get-FileHash -Algorithm SHA256 -LiteralPath '.\WenShu-0.1.0-alpha.1-setup-x64.exe'
Get-Content -LiteralPath '.\SHA256SUMS.txt'
```

文件名和 64 位十六进制值必须逐项一致。哈希只能证明下载字节与清单一致；当前清单和 EXE 没有
受信任发布者签名，不能单独证明公共信任身份。
